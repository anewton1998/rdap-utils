Create a plan to implement this rust program that is to be three binaries.
The first binary is to implement the finding IP networks program described here: https://rdap.rcode3.com/misc/finding_ip_networks.html
The next binary is to implement the finding protected domains program described here: https://rdap.rcode3.com/misc/finding_protected_domains.html
And the final binary is implement the networks of nameservers program described here: https://rdap.rcode3.com/misc/networks_of_nameservers.html
Each program is to use the clap crate from commmand line arguments.
Each program is to read a list of domains either as a csv file or plain text file. for csv files, the user should be able to specify the column holding the domain name.
The user is allowed to pick the output as csv, json, nd-json (also known as json lines and jsonl), or json sequences (RFC7464).
The binaries are to use the icann-rdap-common and icann-rdap-client crates for doing RDAP work.
The plan should include using sub-agents and a todo list.
